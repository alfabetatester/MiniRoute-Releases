# MiniRoute — APK Releases

Public distribution of signed MiniRoute Android APKs. The source and CI configuration remain in a separate private repository.

Download APKs from [GitHub Releases](https://github.com/alfabetatester/MiniRoute-Releases/releases), and verify `SHA256SUMS` and the signing certificate.

Automated builds from upstream updates are prereleases until tested on a physical device. Android requires confirmation to install APK updates.
